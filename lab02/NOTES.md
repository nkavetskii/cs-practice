Git — это система контроля версий.
GitHub — это веб-платформа для работы с репозиториями
git status - показывает состояние файлов
git diff - показывает изменения, не добавленные в индекс
git diff --staged - показывает изменения,  добавленные в индекс
Ветка — это именованный динамический указатель на последний коммит в независимой линии разработки
При новом коммите указатель ветки сдвигается вперед на этот новый коммит.
Слияние объединяет изменения из одной ветки в другую, перенося общую историю в единую линию разработки.
